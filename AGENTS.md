Before running the robot arm for the first time in a session, read and follow [`docs/scene-setup.md`](docs/scene-setup.md), including its camera exposure, framing, and fresh-image checks.

For physical Follower commands, a software stop, recording abort, exception, or controller disconnect must leave the Follower holding its measured position with torque enabled. Before disconnecting, command the current measured position as the hold goal and verify the goal and `Torque_Enable = 1` on all six motors; disconnect with `disable_torque=False`. Inspect an existing command's exit path before using it; do not run one that automatically releases Follower torque on stop or disconnect. An explicit operator command to turn torque off in the UI is an exception: execute it and verify `Torque_Enable = 0` on all six motors. If communication fails and the hold cannot be verified, report that uncertainty immediately and use the physical power cutoff only when needed for safety. A software rule cannot preserve torque through power loss, motor fault, or a disconnected motor cable. Do not add Leader/Follower position-divergence abort limits to teleoperation capture or replay.
