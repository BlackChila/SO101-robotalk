# RoboTalk development priorities

This personal research prototype focuses on SO-101 conversation. Priorities are
not a delivery schedule; see [contribution guidance](CONTRIBUTING.md).

- Reproduce installation on a clean Linux ARM64/GB10 system, including the shared robot runtime.
- Supply an independent reproducible MolmoAct2 environment.
- Validate local Qwen speech, concurrent runtimes and task tools on the reference host.
- Improve hardware configuration portability while retaining identity and hold checks.
- Validate stop, return/recovery, tracking and conversation behavior under supervision.
- Pin dialogue-model and Piper voice downloads more precisely.

Licensing and media review remain tracked in the
[publication checklist](docs/publishing-checklist.md). Software checks do not
establish reliable manipulation or compatibility with another robot.
